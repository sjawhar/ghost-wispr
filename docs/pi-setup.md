# Raspberry Pi Setup

Ghost Wispr runs on a Raspberry Pi with a USB microphone, serving a web UI over Tailscale HTTPS.

## Prerequisites

Install on the Pi before running setup:

```bash
# System packages
sudo apt update && sudo apt install -y libportaudio2 portaudio19-dev

# Go + Node.js (via mise, or install manually)
# https://mise.jdx.dev

# Tailscale
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
```

## First-Time Setup

Clone the repo and run the setup script:

```bash
git clone https://github.com/sjawhar/ghost-wispr.git ~/ghost-wispr
cd ~/ghost-wispr
make setup
```

This will:
1. Create `/opt/ghost-wispr/` with config templates
2. Install a systemd user unit (auto-starts on boot)
3. Enable lingering (runs without a login session)
4. Set up Tailscale HTTPS serve on port 443

After setup, edit the config files:

```bash
# Add your API keys
nano /opt/ghost-wispr/.env

# Customize settings (sample rates, summarization model, presets)
nano /opt/ghost-wispr/ghost-wispr.yaml
```

Then deploy:
```bash
make deploy
```

## USB Microphone

Ghost Wispr uses PortAudio and grabs the system's default capture device. Plug in a USB mic and verify it's detected:

```bash
arecord -l
```

If using usbguard, you may need to authorize the device after plugging in. Then restart the service so it picks up the mic.

The app tries sample rates in order: 16000, 48000, 44100, 32000, 24000 Hz. Most USB mics support at least one of these.

## Day-to-Day

### Service management

```bash
systemctl --user start ghost-wispr
systemctl --user stop ghost-wispr
systemctl --user restart ghost-wispr
systemctl --user status ghost-wispr
```

### Deploy a new version

From any workspace on the Pi:

```bash
make deploy
```

### Local development

Run a dev instance on `:8081` without touching production:

```bash
make run
```

This builds and runs locally. The production instance stays running on `:8080`.

### Check running version

```bash
curl -s localhost:8080/api/version
# or remotely via Tailscale:
curl -s https://ghost-wispr.<tailnet>.ts.net/api/version
```

## Architecture

```
~/ghost-wispr/          # Git repo with jj workspaces
├── default/            # Default workspace
├── config/             # Feature workspace (or any others)
└── ...

/opt/ghost-wispr/       # Production runtime (NOT a workspace)
├── ghost-wispr         # Binary (copied by make deploy)
├── ghost-wispr.yaml    # Config
├── .env                # API keys + GHOST_WISPR_ADDR
└── data/
    ├── ghost-wispr.db  # SQLite database
    └── audio/          # Recorded audio files

~/.config/systemd/user/
└── ghost-wispr.service # Auto-generated by setup.sh
```

Tailscale serve proxies `https://<hostname>:443` → `http://127.0.0.1:8080`. The app only listens on localhost.
